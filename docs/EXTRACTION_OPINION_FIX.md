# 기억 추출에서 화자의 평가가 빠지는 문제 (2026-10-05)

## 증상
업로드한 txt:

> 영수 오빠랑 김치볶음밥을 먹었다 / 오빠가 해줬다 ㅋㅋㅋㅋ 왜냐면 가위바위보에 져서.. / 근데 다음에는 꼭 져야 겠다고 생각했다 너무 맛없어 / 영수 오빠는 음식을 못하나보다

추출된 요약: "영수 오빠와 가위바위보에서 져서 김치볶음밥을 먹었고, 다음에는 꼭 지려고 생각했다."
→ "너무 맛없다", "음식을 못하나 보다"가 빠졌고, "오빠가 해줬다"도 흐려졌다.

## 원인
[extraction.py](../backend/app/prompts/extraction.py)의 프롬프트에 "환각 금지·근거 인용" 규칙만 있고, 요약이 화자의 평가·감상·결과를 보존해야 한다는 규칙이 없었다. 모델은 사건 뼈대만 남겼다.

## 수정
`summary`가 사건의 모든 구별되는 사실(누가 무엇을 했는지, 결과, 맛·어려움·후회·다음 다짐 같은 화자 본인의 평가)을 담도록 규칙을 추가했다. 평가는 객관적 사실이 아닌 화자의 견해로 쓰게 했다. 스키마·검증 코드는 바꾸지 않았다. 이전 프롬프트는 `MEMORY_EXTRACTION_SYSTEM_PROMPT_BEFORE`로 남겨 비교에 쓴다.

## 전후 비교
`PYTHONPATH=. uv run python scripts/compare_extraction_prompt.py` — 같은 텍스트, gemma4:e2b, temperature 0, 3회.

| | 평가("맛없다/못한다") 보존 |
|---|---|
| 수정 전 | 1/3 |
| 수정 후 | 3/3 |

수정 전에는 3회 중 2회가 "다음에 지겠다" 정도로만 쓰거나 "함께 먹었다"로 끝났다. 수정 후에는 3회 모두 맛없다는 평가와 "음식을 못하나 보다"가 요약에 들어갔고, 화자의 견해로 표현됐다.

## 한계
- 표본은 한 텍스트에 3회뿐이다. 판정은 키워드("맛없", "못") 포함 여부라 느슨하다.
- 수정 후 요약에 "화자는 …" 같은 3인칭 표현이 늘었다.
- 이미 저장된 기억은 바뀌지 않는다. 같은 파일을 다시 업로드(재추출)해야 반영된다.
- "다음에는 꼭 져야겠다"처럼 원문 자체가 모호한 표현은 모델이 해석한다(원문 오타일 가능성).
