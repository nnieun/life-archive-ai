# 음식점명 기억 빈칸

음식이나 간식을 먹었다는 사건은 기억되지만 가게 이름이 빠진 경우를
`food_place_name` 기억 빈칸으로 등록합니다. 예를 들어 “매일 먹던 떡볶이”와
같은 표현이 구조화 기억에 남으면 기억 빈칸 화면에서 해당 장소명을 확인할 수
있습니다.

이 빈칸에서 `인터넷에서 단서 찾기`를 누르면 사용자의 동의 아래 공개 웹 검색을
수행합니다. 검색 결과는 개인 기억의 확정 사실이 아니라 참고 후보이며, 사용자가
직접 확인하고 확정해야 기억에 반영됩니다.

검색 결과가 없거나 개인 기록만으로 가게를 특정할 수 없으면 후보를 만들지
않습니다. “대구 중리동”, “달서초등학교”, “매일 먹던 떡볶이”처럼 원문에 있는
단서가 많을수록 검색 품질이 좋아집니다.
