# 업로드 임베딩 일괄 처리

기억별 API 왕복 대신 변경된 기억을 기본 64개씩 묶어 임베딩한다.
해시와 모델 버전이 같은 기억은 재호출하지 않고, 전체 재동기화도 같은 경로를 쓴다.
기억 추출 LLM 호출 자체는 병렬화하지 않았으며 실제 업로드 시간 개선율은 측정하지 않았다.
API 비용이 무료가 되는 변경은 아니다.

업로드는 쓰기 전에 모든 대상 ID를 기록해 부분 성공 후 실패한 벡터도 롤백 대상으로 삼는다.
배치 개수와 빈 벡터를 검증한 뒤 저장한다.
검증: test_vector_index의 배치 호출 수·재호출 생략, test_ingestion의 부분 실패·재시도.
