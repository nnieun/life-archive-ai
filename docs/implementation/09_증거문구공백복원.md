# 기억 추출 증거 문구 공백 복원

## 문제

구조화 출력 모델이 원문을 인용할 때 줄바꿈을 공백으로 바꾸거나,
연속 공백을 하나로 줄이는 경우가 있었다. 기존 검증은 완전한 문자열 일치만
허용해 실제 내용은 존재해도 전체 업로드를 실패시켰다.

## 변경

원문과 증거 문구를 비교할 때 공백·줄바꿈만 하나의 공백으로 접어 비교한다.
일치하면 원문 문자열의 실제 시작·끝 위치를 사용한다. 문장, 이름, 숫자 등
내용이 달라 원문에서 찾을 수 없는 문구는 여전히 오류로 처리한다.

## 검증

기존 기억 추출 테스트와 공백 복원 테스트 **25개 통과**.
실제 API나 `.env`, 사용자 원본은 사용하지 않았다.
