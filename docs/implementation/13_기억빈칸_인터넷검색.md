# 기억 빈칸 인터넷 검색

## 구현 내용

기억 빈칸 화면에 기존 기록 검색과 별도로 `인터넷에서 단서 찾기` 기능을
추가했습니다. 사용자가 인터넷 검색 동의를 선택한 경우에만 LangGraph의
`search_web` 도구가 공개 웹 검색을 수행합니다.

검색 결과는 확정된 기억이 아니라 후보를 뒷받침하는 외부 단서로 저장됩니다.
후보 화면에서는 외부 출처 제목과 링크를 확인할 수 있으며, 사용자가 후보를
직접 확인하기 전에는 원래 기억을 변경하지 않습니다.

## 안전 장치

- 동의하지 않은 경우 웹 도구는 검색하지 않습니다.
- 검색 결과는 기존 기록과 동일하게 근거 문장 검증을 통과해야 후보가 됩니다.
- 외부 출처는 `external_sources`로 별도 저장합니다.
- 검색어에는 기억의 단서가 포함될 수 있으므로 화면에서 동의를 명시적으로 받습니다.

## 사용 방법

1. `기억 빈칸`에서 빈칸을 엽니다.
2. `인터넷 검색에 사용`을 선택합니다.
3. `인터넷에서 단서 찾기`를 누릅니다.
4. 제안된 후보와 외부 출처를 확인한 뒤 직접 선택·확정합니다.

검색 결과가 없거나 근거 문장이 후보와 일치하지 않으면 기억은 자동으로
수정되지 않습니다.
