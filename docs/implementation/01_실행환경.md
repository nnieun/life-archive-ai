# Python 3.13 검증 환경

기존 `.venv`는 삭제된 WindowsApps 실행 파일을 참조하고 있어 실행되지 않았다.
기존 환경과 사용자 데이터를 보존하고 uv의 Python 3.13으로 `.venv-review`를 만들었다.
의존성은 requirements.txt와 pytest로 설치한다. `.env`는 열거나 변경하지 않는다.

```powershell
uv venv .venv-review --python 3.13
uv pip install --link-mode=copy --python .venv-review/Scripts/python.exe -r requirements.txt pytest
```

테스트에서는 dotenv 파일 로딩을 차단하고 실제 API 대신 테스트 대역을 사용한다.
기존 `.venv`는 자동으로 교체하지 않았으므로 기존 실행 명령의 경로는 여전히 별도 복구가 필요하다.

새 환경에서 실행하려면 아래 명령을 각각 다른 PowerShell 창에서 실행한다.
애플리케이션을 사용자가 실행할 때는 기존 설정 로더가 로컬 설정을 불러온다.

```powershell
.\.venv-review\Scripts\python.exe -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8000
.\.venv-review\Scripts\python.exe -m streamlit run frontend/app.py
```
