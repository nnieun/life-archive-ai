# 증거 문구 불일치 시 업로드 보호

모델이 한 배치에 여러 기억을 반환할 때 하나의 증거 문구만 원문에 없는 경우,
기존에는 모든 기억을 버리고 업로드 전체를 실패시켰다. 이제 원문에서 확인되지
않는 후보만 제외하고, 확인 가능한 후보는 계속 저장한다.

원문에 없는 후보는 절대 저장하지 않는다. 따라서 일부 기억이 빠질 수 있지만
허위 출처가 저장되는 일은 막는다. 해당 빈칸은 사용자가 원본을 보완하거나
다시 업로드해 확인할 수 있다.

검증: 유효 후보와 유효하지 않은 후보가 함께 있는 배치에서 유효 후보만 남기는 테스트.
