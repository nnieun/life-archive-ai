# PDF 업로드 지원 확인

기존 화면은 TXT/PDF 업로드를 허용하고, 백엔드는 pypdf로 페이지 텍스트를 추출한 뒤
TXT와 같은 분할 → 기억 추출 → SQLite 저장 → 인덱싱 경로로 처리한다.
따라서 기능을 중복 구현하지 않고 정상 PDF 성공 경로의 회귀 테스트를 추가했다.

- 텍스트 PDF: 지원한다. PDF 내 글꼴 인코딩에 따라 추출 품질은 달라질 수 있다.
- 스캔·사진만 있는 PDF: OCR이 없어 지원하지 않는다.
- PDF 출처 위치: 실제 페이지가 아닌 추출 텍스트 줄 번호다.

`tests/test_pdf_ingestion.py`는 임시 PDF 바이트를 실제 pypdf로 읽고,
모의 추출 모델·인덱스로 기억과 출처 저장, 원본 바이트 보존을 확인한다.
텍스트 없는 PDF는 추출 모델 호출 전에 거부되는지도 검증한다.
사용자 파일, `.env`, 실제 API는 사용하지 않는다.

검증 결과: PDF 업로드 및 원문 로더 테스트 **12개 통과** (4.76초).
실제 API를 통한 모델 응답까지 확인한 결과는 아니다.
