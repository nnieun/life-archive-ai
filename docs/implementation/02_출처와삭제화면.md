# 출처 버튼과 삭제 후 화면 상태

## 변경

- 출처 버튼 키에 대화 메시지 또는 자서전 장 범위를 포함한다.
- 한 답변에서 같은 기억의 출처가 여러 개여도 이동 버튼은 한 개만 표시한다.
- 삭제 API가 성공한 경우 현재 브라우저 세션의 대화, 세션 ID, 선택 기억,
  자서전 작성 대기를 비운다. 실패한 삭제에서는 화면 상태를 보존한다.
- 서로 다른 브라우저 세션을 원격으로 비우는 기능은 포함하지 않는다.

## 검증

`tests/test_frontend_citations.py`에서 반복 출처의 키 고유성과 중복 제거,
삭제 상태 초기화의 반복 호출 안전성 및 무관한 사용자 설정 보존을 확인한다.
